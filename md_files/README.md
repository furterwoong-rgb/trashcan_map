# 쓱싹 (내 주변 쓰레기통 찾기) 🗑️

스마트폰 브라우저에서 1초 만에 켜지는 모바일 퍼스트 웹앱 **"쓱싹(가제: 내 주변 쓰레기통 찾기)"** MVP 프로젝트입니다.

---

## ✨ 주요 기능
- **모바일 최적화 레이아웃 (Mobile-First)**: 지도 풀스크린, 상단 카테고리 필터 칩, 하단 토스/당근 감성의 바텀 시트
- **내 위치 기반 자동 추적**: HTML5 Geolocation API 연동 및 파란색 펄스 핑(Pulse dot) 마커 표시 (거부 시 강남역 11번 출구 폴백)
- **최근접 쓰레기통 자동 탐색**: Haversine 공식을 사용해 내 위치와 쓰레기통 간의 정밀 거리 및 도보 시간 산출
- **방향 안내 점선 (Polyline)**: 내 위치에서 가장 가까운 쓰레기통까지 지도상 애니메이션 대시 점선 표시
- **원터치 길찾기 연동**: 카카오맵, 네이버 지도, 구글 지도 도보 길찾기 다이렉트 연결
- **카테고리 필터**: 전체 / 일반·재활용 / 담배꽁초 수거함 실시간 필터링

## 🛠️ 기술 스택
- **HTML5 & Vanilla JavaScript**
- **Tailwind CSS** (CDN)
- **Leaflet.js** (오픈소스 지도) & **CartoDB Positron** (미니멀 화이트 맵 타일)
- **Pretendard Font**

## 🚀 실행 방법
별도의 빌드 과정 없이 `index.html` 파일을 브라우저로 열면 바로 실행됩니다.
```bash
# 로컬 웹 서버 실행 예시
python3 -m http.server 3000
# 브라우저에서 http://localhost:3000 접속
```
